# One Star, Written in Sap

`One star — my human waters me like a rumor, forgets me like a password, then calls my yellow leaves 'a vibe.' I'm not wilting, I'm documenting for the review.`

Run it with `node main.ts` — it prints exactly the single entry line to stdout.

One sentence explaining the joke: A houseplant reviews its neglectful human like a disgruntled Yelp customer, treating chronic under-watering and "a vibe" gaslighting as valid grounds for a single star.
The plant has since filed a follow-up: the watering can is still missing.
